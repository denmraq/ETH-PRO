ETH PRO — ЧИСТАЯ УСТАНОВКА ПО GEMINI

ЗАГРУЗИТЬ В КОРЕНЬ GITHUB:
1. server.py
2. train_model.py
3. requirements.txt
4. Procfile

В ПАПКУ static:
5. static/index.html

ПОСЛЕ ПЕРВОГО ЗАПУСКА:
1. Установить зависимости: pip install -r requirements.txt
2. Один раз запустить:
   python train_model.py

После обучения появятся:
- catboost_eth_model.cbm
- crypto_historical_data.csv

Для работы 12h ML файл catboost_eth_model.cbm должен лежать в корне рядом с server.py.

Далее обычный запуск:
uvicorn server:app --host 0.0.0.0 --port 8000
