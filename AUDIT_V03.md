# Audit V0.2 → V0.3

Исправлено:
1. Решения больше не принимаются по текущей незакрытой свече. Используются только закрытые 4H/1H/15m/5m бары.
2. Исправлена ошибка veto: в V0.2 общий ATR-фильтр добавлялся в текст, но не блокировал LONG/SHORT.
3. Введены direction-specific BLOCK_LONG / BLOCK_SHORT.
4. Добавлен минимальный R:R и проверка слишком далёкого структурного стопа.
5. Снижена роль псевдоликвидности: swing high/low теперь только контекст с меньшим весом.
6. В интерфейсе явно указано, что liquidity — proxy, а не liquidation heatmap.
7. Trade-flow/CVD proxy теперь показывает, какой реальный временной интервал покрывают последние 1000 сделок.
8. Добавлен Time Engine на исторических 15m аналогах:
   - WATCH_LONG / WATCH_SHORT / ACTIVE_LONG / ACTIVE_SHORT / WAIT;
   - entry window;
   - P(TP first), P(SL first), P(neither in 4h);
   - 25/50/75 percentile времени до TP;
   - динамическая time invalidation.
9. При баре, где OHLC показывает одновременное касание TP и SL, бэктест консервативно считает SL, потому что порядок внутри свечи неизвестен.

Ограничения:
- Исторические аналоги — простая статистическая модель, не ML и не гарантия.
- Для серьёзного CVD нужен фиксированный временной поток и желательно несколько бирж.
- Для настоящей карты ликвидаций нужен отдельный провайдер данных.
- Перед реальными деньгами нужен полноценный event-driven backtest и paper trading.
