# PRO V1.24 — FUTURE ONLY

- Полностью убрана интеграция liquidation map/heatmap из расчёта и интерфейса.
- Убраны карточки Push priority / threshold и зависимость UI от `/api/priority`.
- Убраны режим скальпинга, текущий LONG/SHORT-сигнал, Fast 1m и текущие диагностические баллы из интерфейса.
- Главный экран показывает только прогноз будущего направления на 1ч / 6ч / 12ч.
- 1ч сохраняет 20-минутный forecast window; 6ч — 60 мин; 12ч — 120 мин.
- Исторические данные используются как обучающая выборка: состояние сейчас -> фактический исход позже.
- Сохранён новостной модуль как фактор внепланового пересмотра только при подтверждённом влиянии рынка.
- Добавлены Kraken и корректный Coinbase 4h fallback для Render.
- UI защищён от `undefined`/`NaN`: при неполном серверном ответе показывает точную ошибку, а не мусорные значения.
