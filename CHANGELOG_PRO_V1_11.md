# PRO V1.11 — Current Price Decision Engine

- Главный сигнал теперь отвечает на один вопрос: **если входить прямо сейчас, какое направление вероятнее — LONG или SHORT?**
- Главный LONG/SHORT берётся из forward-прогноза ближайшего 1 часа, а не из старой зоны входа или суммы баллов.
- **Вход = актуальная цена в момент обновления.** Поиск отката/будущей точки входа убран из пользовательской логики.
- Верхняя плашка показывает: направление + текущая цена + вероятность на 1 час.
- Прогноз 1ч / 6ч / 12ч сохранён.
- TP1 / TP2 / TP3 теперь строятся от текущей цены по forward-распределениям 1ч / 6ч / 12ч.
- Stop также строится от текущей цены по неблагоприятному 1-часовому диапазону с ATR-защитой.
- LONG/SHORT score остаются диагностикой и больше не являются главным арбитром направления.
- Убран пользовательский смысл «вход на откате»; блок называется «Уровни от текущей цены».
