# GitHub + Render: separate PRO application

1. Create a new GitHub repository, e.g. `eth-entry-radar-pro`.
2. Upload the **contents of this folder** to the repository root.
3. In Render choose **New -> Blueprint** and connect that repository.
4. Render reads `render.yaml` and creates `eth-entry-radar-pro` with a persistent disk.
5. In Render Environment add the VAPID variables generated by `python generate_vapid_keys.py`.
6. Deploy. Open `/api/health` and confirm `"ok": true`.
7. Open the HTTPS URL in Safari -> Share -> Add to Home Screen.
8. Launch from the Home Screen and enable Push.

This is a separate app/repository, so experiments in PRO do not modify the Core application.
