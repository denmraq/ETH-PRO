# Два независимых приложения

## 1. Сохранить текущее приложение
Не удаляйте текущий GitHub-репозиторий и текущий Render Web Service. Это остаётся ETH Radar Core на старом URL.

## 2. Создать PRO отдельно
1. В GitHub создайте новый репозиторий, например `eth-entry-radar-pro`.
2. Загрузите в него содержимое этого архива (файлы должны лежать в корне репозитория).
3. В Render создайте **New Web Service** и подключите новый репозиторий.
4. Используйте новый service name, например `eth-entry-radar-pro`.
5. После deploy откройте новый HTTPS URL в Safari → Поделиться → На экран «Домой».
6. Назовите иконку `ETH Radar PRO`.

В результате старый Core и новый PRO имеют разные GitHub-репозитории, Render-сервисы, URL и iPhone-иконки и не мешают друг другу.
